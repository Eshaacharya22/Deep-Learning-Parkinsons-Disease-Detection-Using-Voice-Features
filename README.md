# Deep Learning Parkinson's Disease Detection Using Voice Features

## 📌 Project Overview

This project uses Deep Learning techniques to assist in the detection of Parkinson's Disease using voice features. The system analyzes relevant voice data and applies machine learning and deep learning models to identify patterns associated with Parkinson's Disease.

## 🚀 Features

* Parkinson's Disease detection using voice features
* Deep Learning-based prediction
* Voice dataset analysis and preprocessing
* Model training and evaluation
* Spiral and wave analysis using a trained model
* Interactive implementation using Google Colab

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* Deep Learning
* Pandas
* NumPy
* Scikit-learn
* Google Colab

## 📂 Project Files

| File                                                   | Description                                     |
| ------------------------------------------------------ | ----------------------------------------------- |
| `Parkinson's__voice_data_set_completed_code_(1).ipynb` | Voice dataset analysis and model implementation |
| `Spiral_wave__(final).ipynb`                           | Spiral and wave analysis implementation         |
| `Front_end_project (1).ipynb`                          | Front-end project implementation                |
| `Spiral & wave.h5`                                     | Trained Deep Learning model                     |
| `parkinsons (1).csv`                                   | Parkinson's voice dataset                       |

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `.ipynb` files using Google Colab or Jupyter Notebook.
3. Install the required Python libraries.
4. Upload or connect the required dataset.
5. Run the notebook cells sequentially.

## 📊 Dataset

The project uses Parkinson's-related voice features for analysis and prediction.
